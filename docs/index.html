Antiloop

An anti-loop watchdog for local LLM agents — catches the tool loop and the repeating-word loop, without an API key, a GPU, or a single third-party package.

View on GitHub Integration manual Press kit

Two failures, two answers

Tool loops

The agent runs the same failing command, re-reads the same file, repeats the same edit. The watchdog detects it, refuses that one call, and hands the model a recovery protocol.

Text loops

The model repeats one word or sentence until the budget ends. A streaming detector fires about a second in, and a final-output transform keeps the loop out of your transcript.

Prevention first

Greedy decoding on a low-bit quantisation is the real cause. With a repetition penalty the same pathological prompt stops itself after 37 repeats instead of 220.

What it does not do

It cannot cancel a model request in flight — hooks may refuse a tool call, not interrupt a generation. It does not call an LLM, does not phone home, cannot stop a process, and every Hermes-side hook fails open: if the watchdog dies, your agent keeps working.

Install

git clone https://github.com/sharenganeye/antiloop-watchdog.git
cd antiloop-watchdog
scripts/start_watchdog.sh        # Windows: .\scripts\start_watchdog.ps1
curl -s http://127.0.0.1:8791/health

Python 3.9+, standard library only. Then follow the integration manual to wire it into Hermes profiles (hooks, consent, plugin, canary, rollback).
